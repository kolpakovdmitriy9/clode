# Лента строк с вставками изображений — анимация при скролле

Секция с «залипающим» (sticky) чёрным экраном, по которому непрерывно бежит
вертикальная лента коротких строк. При скролле:

- лента **едет вертикально** пропорционально прогрессу прокрутки секции —
  строка за строкой проходит через центр экрана и уезжает дальше, с лёгкой
  инерцией («догоняние» скролла, `ease`);
- строка, оказавшаяся **в центре экрана, — яркая, чёткая и в полный размер**;
  по мере ухода к верхнему или нижнему краю она **гаснет, слегка размывается
  и уменьшается** — эффект прожектора/фокуса;
- текст набран крупным жирным шрифтом с **металлическим бликом**
  (вертикальный градиент светлый → серый → светлый через `background-clip:text`),
  часть слов дополнительно выделена курсивом для акцента;
- в некоторых строках **слово заменено на вставку-картинку** — маленькую
  скруглённую плашку высотой со строку текста; вставка гаснет и размывается
  вместе со своей строкой по тем же правилам, что и текст;
- по верхнему и нижнему краю экрана лежит статичный **градиент-туман**,
  дополнительно скрадывающий строки на подходе к рамке.

Сцена всегда тёмная (чёрный фон), независимо от темы страницы — это часть
визуального решения самого эффекта, а не адаптивная тема.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: сцена, 9 строк ленты, три вставки-картинки (инлайновые SVG) |
| `styles.css` | оформление, sticky-сцена, металлический текст, адаптив |
| `script.js`  | вся анимация: прогресс скролла, позиция ленты, угасание/размытие строк по расстоянию до центра |

Зависимостей нет — достаточно открыть `index.html` в браузере.

## Настройка

Основные параметры — объект `CFG` в начале `script.js`:

| Параметр | Значение | Смысл |
|---|---|---|
| `ease` | 0.16 | «догоняние» скролла инерцией: меньше — тягучее движение ленты |
| `focus` | 0.30 | половина высоты чёткой зоны в центре экрана, в долях высоты экрана |
| `fadeSpan` | 1.15 | на какой доле `focus` строка гаснет полностью |
| `maxBlur` | 3.2 | максимальное размытие строки у края экрана, px |
| `scaleEdge` / `scaleFocus` | 0.92 / 1 | масштаб строки у края и в фокусе |
| `minOpacity` | 0.03 | строка не гаснет до абсолютного нуля |

В CSS:

- `--lines` — количество строк ленты (должно совпадать с числом `.line` в разметке);
- `--line-vh` — сколько vh скролла приходится на переход между соседними строками;
- `--stage-bg` / `--stage-fade` — цвет фона сцены и туман по краям.

## Как добавить строку или вставку

1. Добавить `<p class="line">…</p>` в `#lines`; курсив — через `<i>слово</i>`.
2. Для вставки-картинки положить внутрь строки `<span class="chip">…</span>`
   с инлайновым SVG внутри (или заменить на `<img>`).
3. Поднять `--lines` в `:root` на количество добавленных строк.

Длина сцены и тайминги пересчитываются автоматически по фактической высоте ленты.

## Поведение

- Прогресс считается от геометрии секции (`getBoundingClientRect`), поэтому
  корректен при любой высоте окна, ресайзе и перезагрузке посреди сцены.
- Положение и состояние каждой строки пересчитывается от её фактического
  `offsetTop`, поэтому вёрстка остаётся корректной при переносе строк и любых
  размерах шрифта.
- Отрисовка идёт в `requestAnimationFrame` и останавливается, когда лента
  догнала скролл, — в покое кадры не тратятся.
- При `prefers-reduced-motion: reduce` инерция отключается, лента следует
  за скроллом 1:1.
