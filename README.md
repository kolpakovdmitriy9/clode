# 3D-барабан из строк со вставками изображений — анимация при скролле

Секция с «залипающим» (sticky) чёрным экраном, на котором крутится настоящий
3D-барабан из коротких строк — не имитация через blur/scale, а честные
`rotateX` + `translateZ` на общей `perspective`. При скролле:

- строки — это грани цилиндра: каждая стоит на своём углу барабана
  (`rotateX`) и вынесена на радиус (`translateZ`), поэтому у них есть
  настоящая перспективная глубина;
- барабан **крутится вокруг горизонтальной оси** пропорционально прогрессу
  прокрутки секции, с лёгкой инерцией («догоняние» скролла, `ease`);
- строка **напротив зрителя (угол ≈0°) стоит вровень с экраном** — крупная,
  чёткая, без искажений; по мере поворота соседние строки **уходят по дуге
  назад**: перспектива их сжимает по вертикали и скашивает, они гаснут
  и слегка размываются — это и есть эффект кругового барабана, а не плоское
  затухание;
- текст набран крупным жирным шрифтом с **металлическим бликом**
  (вертикальный градиент светлый → серый → светлый через `background-clip:text`),
  часть слов дополнительно выделена курсивом для акцента;
- в некоторых строках **слово заменено на вставку-картинку** — маленькую
  скруглённую плашку высотой со строку текста; вставка едет по дуге вместе
  со своей строкой и гаснет по тем же правилам;
- строки, ушедшие за грань видимости барабана (обратная сторона цилиндра),
  не рисуются вовсе — `backface-visibility:hidden` плюс явное отключение
  по углу, чтобы не было зеркального текста.

Сцена всегда тёмная (чёрный фон), независимо от темы страницы — это часть
визуального решения самого эффекта, а не адаптивная тема.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: сцена, 9 строк барабана, три вставки-картинки (инлайновые SVG) |
| `styles.css` | оформление, sticky-сцена, `perspective`/`preserve-3d`, металлический текст, адаптив |
| `script.js`  | вся 3D-математика барабана: угол каждой строки, радиус, поворот по скроллу, угасание/размытие по углу |

Зависимостей нет — достаточно открыть `index.html` в браузере.

## Как это устроено геометрически

Радиус барабана подбирается из реальной высоты строки, чтобы шаг между
строками у фронта цилиндра (угол 0°) совпадал с их высотой:

```
radius = lineHeight / (angleStep в радианах)
```

Сама лента (`#lines`) сдвинута назад на `translateZ(-radius)`, поэтому
строка под углом 0° оказывается ровно на плоскости экрана, а остальные —
уже позади неё, на дуге цилиндра. Каждая строка получает свой угол:

```
angle(i) = i * angleStep + entryPad - rotation
transform: translate(-50%, -50%) rotateX(-angle) translateZ(radius)
```

`rotation` растёт вместе с прогрессом скролла секции — это и вращает
барабан.

## Настройка

Основные параметры — объект `CFG` в начале `script.js`:

| Параметр | Значение | Смысл |
|---|---|---|
| `angleStep` | 18° | угловой шаг между соседними строками на барабане |
| `edgeAngle` | 86° | за этим углом строка на обратной стороне барабана — не рисуется |
| `visibleLimit` | 80° | угол, после которого строка полностью гаснет |
| `hold` | 0.12 | доля `visibleLimit`, где строка ещё полностью яркая (узкое плато — кривизна барабана видна пошире) |
| `entryPad` | 96° | запас угла для входа/выхода первой и последней строки |
| `perspectivePx` | 720 | должно совпадать со значением `perspective` в CSS (`.reel`) — чем меньше, тем сильнее эффект «бочки» |
| `ease` | 0.14 | «догоняние» скролла инерцией по углу барабана |
| `maxBlur` | 2.6 | максимальное размытие строки у грани видимости, px |

В CSS:

- `--lines` — количество строк барабана (должно совпадать с числом `.line` в разметке);
- `--line-vh` — сколько vh скролла приходится на переход между соседними строками;
- `--stage-bg` / `--stage-fade` — цвет фона сцены и туман по краям;
- `perspective` на `.reel` — вместе с `perspectivePx` в JS задаёт «кривизну» барабана.

## Как добавить строку или вставку

1. Добавить `<p class="line">…</p>` в `#lines`; курсив — через `<i>слово</i>`.
2. Для вставки-картинки положить внутрь строки `<span class="chip">…</span>`
   с инлайновым SVG внутри (или заменить на `<img>`).
3. Поднять `--lines` в `:root` на количество добавленных строк.

Радиус барабана и тайминги пересчитываются автоматически по фактической
высоте строк.

## Поведение

- Прогресс считается от геометрии секции (`getBoundingClientRect`), поэтому
  корректен при любой высоте окна, ресайзе и перезагрузке посреди сцены.
- Радиус барабана пересчитывается от фактической высоты строки на `resize`,
  поэтому вёрстка остаётся корректной при любых размерах шрифта.
- Отрисовка идёт в `requestAnimationFrame` и останавливается, когда барабан
  догнал скролл, — в покое кадры не тратятся.
- При `prefers-reduced-motion: reduce` инерция отключается, барабан следует
  за скроллом 1:1.
