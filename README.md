# Круг с делениями — анимация при скролле

Секция с «залипающим» (sticky) кругом из делений. При скролле:

- круг **вращается** пропорционально прогрессу прокрутки секции;
- деления в верхней зоне **вытягиваются как магнитом** — длина и толщина растут
  по гауссовой кривой от 12 часов, с небольшой инерцией и усилением на быстром скролле;
- пришедшие снизу деления **плавно перекрашиваются градиентом** серый → тёмный → акцент,
  верхнюю зону дополнительно подсвечивает мягкая дуга и свечение самых «горячих» штрихов;
- внутри круга **сменяются 3 блока** (бейдж + заголовок + описание) с кроссфейдом
  и смещением, снизу — индикатор шагов.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: сцена, SVG-циферблат, три текстовых блока |
| `styles.css` | оформление, sticky-сцена, типографика, адаптив |
| `script.js`  | вся анимация: прогресс скролла, геометрия делений, градиент нагрева, смена блоков |

Зависимостей нет — достаточно открыть `index.html` в браузере.

## Настройка

Основные параметры — объект `CFG` в начале `script.js`:

| Параметр | Значение | Смысл |
|---|---|---|
| `tickCount` | 72 | количество делений по кругу |
| `radius` | 196 | радиус окружности в единицах viewBox (560×560) |
| `lenBase` / `lenMax` | 16 / 62 | длина обычного и максимально «вытянутого» деления |
| `widthBase` / `widthMax` | 1.05 / 2.6 | толщина обычного и «горячего» деления |
| `sigma` | 26° | ширина зоны магнита (гауссов спад) |
| `rotationTotal` | 320° | полный поворот круга за всю сцену |
| `inertia` | 0.14 | «догоняние» скролла: меньше — тягучее |
| `velBoost` | 0.55 | доп. вытягивание на быстром скролле |
| `ramp` | массив | градиент нагрева деления; последний стоп берётся из `--accent` |

В CSS:

- `--accent` — акцентный цвет верхней зоны;
- `--slides` — количество блоков (должно совпадать с числом `.slide` в разметке);
- `--stage-vh` — сколько vh скролла приходится на один блок.

## Как добавить четвёртый блок

1. Скопировать `<article class="slide">…</article>` в `#slides`.
2. Добавить `<i></i>` в `.dots`.
3. Поднять `--slides` до `4` в `:root`.

Центры блоков, длина сцены и тайминги пересчитываются автоматически.

## Поведение

- Прогресс считается от геометрии секции (`getBoundingClientRect`), поэтому корректен
  при любой высоте окна, ресайзе и перезагрузке посреди сцены.
- Отрисовка идёт в `requestAnimationFrame` и останавливается, когда круг догнал скролл, —
  в покое кадры не тратятся.
- При `prefers-reduced-motion: reduce` инерция отключается, круг следует за скроллом 1:1.
