# Круг с делениями — анимация при скролле

Секция с «залипающим» (sticky) кругом из делений. При скролле:

- круг **вращается** пропорционально прогрессу прокрутки секции;
- деления в верхней зоне **вытягиваются как магнитом в обе стороны** — базовая часть
  висит на окружности, а прирост расходится наружу и внутрь (пропорция — `growOut`),
  длина и толщина растут по гауссовой кривой от 12 часов, с инерцией и усилением
  на быстром скролле;
- **магнит работает только во время движения**: через ~0.4 c после остановки круг
  за пару секунд выравнивается, доводится до ближайшего деления и оставляет
  одну удлинённую стрелку ровно на 12 часах;
- пришедшие снизу деления **плавно перекрашиваются градиентом** серый → глубокий оттенок
  акцента → акцент, верхнюю зону подсвечивает мягкая дуга и свечение самых «горячих» штрихов;
- в простое работает **магнит под курсором**: если водить мышкой вдоль кольца,
  деления в этом месте так же вытягиваются, окрашиваются и подсвечиваются;
- внутри круга **сменяются 3 блока** (бейдж + заголовок + описание) с кроссфейдом,
  и **вместе с текстом переливается акцентный цвет**: 1-й блок — красный, 2-й — зелёный,
  3-й — синий. Цвет держится на «плато» блока и меняется ровно во время смены текста.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: сцена, SVG-циферблат, три текстовых блока |
| `styles.css` | оформление, sticky-сцена, типографика, адаптив |
| `script.js`  | вся анимация: прогресс скролла, геометрия делений, градиент нагрева, смена блоков |

Зависимостей нет — достаточно открыть `index.html` в браузере.

## Настройка

Основные параметры — объект `CFG` в начале `script.js`:

| Параметр | Значение | Смысл |
|---|---|---|
| `tickCount` | 72 | количество делений по кругу |
| `radius` | 208 | радиус неподвижной внешней окружности (viewBox 560×560) |
| `lenBase` / `lenMax` | 16 / 56 | длина обычного и максимально «вытянутого» деления (растут внутрь) |
| `lenRest` | 22 | добавка к стрелке на 12 часах в состоянии покоя |
| `growOut` | 0.5 | куда уходит прирост: `0` — только внутрь, `1` — только наружу, `0.5` — поровну |
| `widthBase` / `widthMax` | 1.05 / 2.6 | толщина обычного и «горячего» деления |
| `sigma` | 26° | ширина зоны магнита (гауссов спад) |
| `rotationTotal` | 320° | полный поворот круга за всю сцену |
| `inertia` | 0.14 | «догоняние» скролла: меньше — тягучее |
| `velBoost` | 0.55 | доп. вытягивание на быстром скролле |
| `idleDelay` | 420 мс | пауза без скролла, после которой круг начинает выравниваться |
| `hoverSigma` | 18° | ширина зоны магнита под курсором |
| `hoverLen` | 34 | насколько вытягиваются деления под курсором |
| `hoverBand` | 0.16 | полоса вокруг кольца (в долях ширины круга), где ловится курсор |
| `attack` / `release` | 0.18 / 0.028 | скорость появления и затухания магнита (≈2 c до ровного круга) |

В CSS:

- `--c1`, `--c2`, `--c3` — акцент каждого текстового блока (для 4-го блока добавьте `--c4`);
- `--accent` — текущий акцент, его пересчитывает скрипт по прогрессу скролла;
- `--tick-cold` / `--tick-mid` / `--tick-hot` — холодная часть градиента нагрева;
- `--slides` — количество блоков (должно совпадать с числом `.slide` в разметке);
- `--stage-vh` — сколько vh скролла приходится на один блок.

## Как добавить четвёртый блок

1. Скопировать `<article class="slide">…</article>` в `#slides`.
2. Поднять `--slides` до `4` в `:root` и задать четвёртый цвет `--c4`.

Центры блоков, длина сцены и тайминги пересчитываются автоматически.

## Поведение

- Прогресс считается от геометрии секции (`getBoundingClientRect`), поэтому корректен
  при любой высоте окна, ресайзе и перезагрузке посреди сцены.
- Отрисовка идёт в `requestAnimationFrame` и останавливается, когда круг догнал скролл, —
  в покое кадры не тратятся.
- При `prefers-reduced-motion: reduce` инерция отключается, круг следует за скроллом 1:1.
- Тёмная тема собрана на тех же переменных: базовые значения в `:root`, переопределение —
  в `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`. Если тёмная тема
  не нужна, достаточно удалить эти два блока.
